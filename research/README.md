# Research sources and archives

This area contains retained source material, not the running React application. It is outside TypeScript's application check and is not automatically copied into the published website.

Project boundaries matter: `iris/`, `shell-game/`, `transit-aware/`, and `model-schmodel/` are separate work. Food Vulnerability's active datasets live in its own Ecoverse and its methodology PDF is hosted under `public/food-vulnerability/`. `conferences/` and `tools/site-history/` preserve source copies without claiming they are the current public edition.

The old primary Iris work is archived while its revision is in progress. Keep its original filenames and content. Do not infer scientific inaccuracies, substitute datasets, or turn source tables into new representations as part of maintenance.

Model schmodel is an emerging thread across the research, not a published new stage. Its source uses Kaggle's API vocabulary where required, but this site does not organize it as a separate "benchmarks" project. The original local run receipts have not been moved, deleted, or published.
